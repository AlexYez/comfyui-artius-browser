## Released and local changes

Паспорт актуальности руководств на 2026-11-02. Версия поставки задаётся в [pyproject.toml](../pyproject.toml), а её изменения — в [CHANGELOG.md](../CHANGELOG.md). Переводы происходят из прежнего README; этот раздел уточняет различия между опубликованным состоянием и локальными дополнениями, не выдавая последние за релиз.

- В опубликованном обновлении от 2026-10-31 два видео переключаются между **Side by side / Рядом** и **Wipe / Шторка** без потери текущего кадра. Compare работает также для трёх и четырёх клипов с общим транспортом; шторка доступна для двух.
- Autoscan индексирует названные output-файлы после каждого завершённого prompt, даже если очередь ещё работает. Запросы сериализованы; быстрые результаты могут объединяться. Полный обход папки остаётся fallback после завершения очереди, когда пути неизвестны, tracker переполнен или точечная индексация не удалась.
- Filename search — режим по умолчанию. Переключатель Prompt включает `search_scope=all`, то есть поиск по индексированному prompt/model text. Устаревший параметр `metadata` отклоняется; это **не** запрет поддерживаемого поиска через `search_scope`.
- Папка workflows разрешается относительно userdata активного профиля ComfyUI. Упоминания `user/default/workflows` в старых переводах описывают обычный default-профиль, а не универсальный путь установки.
- Указанная в переводах формула автоматического числа workers относится к FFmpeg/ffprobe. Hash-пул задаётся отдельно. Проверяемые значения находятся в [ts_settings.py](../tsab/ts_settings.py), а не в результатах старого замера скорости.

### Local draft features

Строки **Export Prompts** и **Copy Path / Copy Paths**, помеченные в таблицах как `local draft`, описывают отдельные изменения рабочей копии сопровождающего. Они не входят в релиз **1.20.3**. Проверяйте состав опубликованного коммита, а не только наличие кнопки в локальной установке сопровождающего.

Основные реализации опубликованного браузера: [panel](../js/ts-artius-browser-panel.js), [viewer](../js/ts-artius-browser-viewer.js), [archive service](../tsab/ts_archive.py), [runtime](../tsab/ts_runtime.py). Детальные developer-команды и память сопровождающего остаются приватными по выбору владельца; они не обязательны для установки опубликованного pack.

## Сброс индекса и полный сброс

Для обычного пересоздания индекса/превью используйте **Rebuild Cache**. Этот путь вызывает `TSResetIndex` и очищает генерируемый кэш; таблица `asset_favorites` не входит в reset SQL, а `config.json` не удаляется. Источники: [TSScanService](../tsab/ts_scan_service.py), [reset SQL](../tsab/ts_db_schema.py).

Удаление всего каталога хранения — отдельный полный сброс с потерей находящихся в нём настроек и избранного. Сначала остановите ComfyUI и сохраните резервную копию каталога, если эти данные нужны. Типовой путь в переводах предполагает стандартный output; реальный root вычисляет [TSStoragePaths](../tsab/ts_storage.py) из output-каталога ComfyUI. Не удаляйте папку исходных ассетов вместо служебного каталога.

## Установка и сведения о среде

Используйте ComfyUI Manager по имени **Timesaver Artius Browser** или Git-инструкции выбранного языка. Минимальные версии и runtime-зависимости определены в [pyproject.toml](../pyproject.toml) и [requirements.txt](../requirements.txt). После установки/изменения Python перезапустите ComfyUI и обновите страницу; после обновления только JS нужен reload браузера.

Тексты о скоростях и результатах прежних аудитов не являются гарантией производительности на любой машине. Например, проверка автоскана от 2026-10-31 использовала короткий image workflow и небольшой WebM; её результаты нельзя автоматически переносить на полную H3 video generation.

## Diagnostics

Для повторяющегося сбоя сохраните вывод терминала, из которого запущен ComfyUI. Расширение использует его logging; собственного обязательного файла журнала не задаёт, а перенаправление в файл зависит от запуска ComfyUI.

В той же установке откройте `GET /asset_browser/version`: ошибки frontend находятся во вложенном массиве `diagnostics.client_errors`, сведения об инструментах — в `diagnostics.tools`, память процесса — в `diagnostics.memory`. Кольцо ошибок текущей вкладки также доступно через `window.tsArtiusBrowser.getRecentErrors()` в консоли браузера. Эти данные помогают отличить проблему события/индексации от отсутствующего FFmpeg или ошибки превью.

Структура ответа задана в [TSHandleVersion](../tsab/ts_routes.py), а диагностические поля собирает [TSCollectDiagnostics](../tsab/ts_runtime.py). Подробная инженерная диагностика входит в приватный development checkout; для пользовательского bug report достаточно перечисленных общедоступных данных и шагов воспроизведения.
